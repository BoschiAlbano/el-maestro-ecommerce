# Decisiones

Registro de decisiones importantes del proyecto, una por archivo, numeradas. Sirven para recordar **por qué** se decidió algo.

Formato de cada archivo:

```
# NNNN — Título

- **Fecha:** AAAA-MM-DD
- **Estado:** Aceptada | Reemplazada por NNNN

## Contexto
## Decisión
## Consecuencias
```

| N.º | Decisión |
|---|---|
| 0001 | Moneda única: pesos argentinos |
| 0002 | Pedidos sin reserva de stock |
| 0003 | El ticket es un documento interno, no fiscal |
