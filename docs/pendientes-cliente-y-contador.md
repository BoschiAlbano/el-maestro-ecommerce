# Mercado Libre y factura electrónica: qué necesitamos de ustedes

**Fecha:** 11 de noviembre de 2026

Vamos a sumar dos cosas al sistema:

1. **Vender por Mercado Libre desde el sistema.** Se eligen los productos, se publican, el stock se actualiza solo y cada compra llega al sistema lista para preparar.
2. **Emitir facturas electrónicas.** Siempre en las ventas de Mercado Libre, y en el local cuando el cajero lo decida.

Para avanzar necesitamos algunas gestiones y respuestas. Están separadas en dos partes: una para el dueño del negocio y otra para el contador. En cada punto indicamos para qué sirve y, cuando ya tenemos una propuesta, cuál es; si están de acuerdo, alcanza con responder "ok".

**4. Si empieza a vender en Mercado Libre antes de que el sistema esté listo, cargar las publicaciones de esta forma.**
Las publicaciones que cargue ahora se van a conectar después con el sistema, y van a conservar sus ventas, sus opiniones y su posición. Para que esa conexión sea automática y sin errores:

- **Cargar un "SKU" en cada publicación** *(actualizado 2026-11-12)*. Puede ser el código de barras del producto o un código propio, con letras y números. El sistema va a tener un campo SKU en cada producto: si es el mismo en los dos lados, el sistema reconoce solo a qué producto corresponde cada publicación. Si no tiene SKU, también sirve que coincida con el código de barras que figura en el sistema. Es lo más importante para que la conexión sea automática.
- **Una publicación por producto.** No cargar el mismo producto en dos publicaciones.
- **No usar variantes** (una misma publicación con varios colores o talles). Si un producto viene en dos colores, son dos productos en el sistema y dos publicaciones.
- **No usar el depósito de Mercado Libre (Full).** El sistema trabaja con el stock del local.
- **Cargar el código universal del producto** (el número del código de barras de fábrica) cuando Mercado Libre lo pida.

Hasta que el sistema esté conectado, el stock de Mercado Libre y el del local se manejan por separado: cada venta de mostrador de un producto publicado hay que descontarla a mano en Mercado Libre, y cada venta de Mercado Libre hay que descontarla en el sistema con un ajuste de stock.

Las ventas de Mercado Libre anteriores a la puesta en marcha no se cargan en el sistema: los reportes van a mostrar Mercado Libre desde ese día.
